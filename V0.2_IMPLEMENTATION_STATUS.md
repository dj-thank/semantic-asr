# Semantic ASR v0.2 implementation status

## Implemented

### Evidence and candidate generation

- path-preserving faster-whisper/CTranslate2 N-best adapter;
- decoder-path provenance and surface-equivalence aggregation;
- immutable observed versus normalized transcript contract;
- context/model/span/calibration-aware evidence cache;
- long-form localized evidence orchestration.

### Lightweight language frontiers

- character N-gram;
- mora N-gram;
- Unicode subword N-gram;
- optional KenLM backend;
- hashed offline probability cache;
- Semantic MBR.

### Learned ranking and fusion

- deterministic linear candidate ranker;
- pairwise preference training;
- listwise semantic-MWER training;
- held-out monotonic ranker calibration;
- acoustically constrained learned fusion;
- progressive budgeted reranking;
- candidate-locked multi-teacher distillation.

### Acoustic verification and selective compute

- candidate-conditioned query-selected acoustic verifier;
- mora/phone/boundary/accent/F0/preservation auxiliary heads;
- adaptive K;
- balanced evidence router;
- runtime pressure throttling with hysteresis;
- Qwen3-ASR second-ear and forced-aligner adapters;
- guarded GER proposal gate.

### Research and deployment

- speaker/source/near-duplicate split isolation;
- rights-gated real-audio candidate generation;
- raw-ASR/Cascade/Semantic-MBR/oracle-at-K benchmark;
- paired group-bootstrap intervals;
- quantization/export deployment gate;
- immutable functional pipeline contracts;
- opt-in self-hosted real-audio workflow;
- Koemo integration contract.
