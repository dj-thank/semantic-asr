## Independently reproduced defects

### #24 — teacher execution bypasses a zero action budget

At the audited revision, longform.py uses `teacher_planned or
self.teacher_policy.should_query(ranked)`. The following model-free reproducer
counts actual teacher calls. It intentionally supplies a fake audio path because
the injected fixture adapters do not decode audio; it is not an audio benchmark.

```python
import importlib.util
import tempfile
from pathlib import Path
from semantic_asr.longform import SemanticASRTranscriber
from semantic_asr.planner import EvidenceBudget
from semantic_asr.teachers import DelayedTeacherPolicy

spec = importlib.util.spec_from_file_location('fixtures', 'tests/test_longform.py')
fixtures = importlib.util.module_from_spec(spec)
spec.loader.exec_module(fixtures)

class CountingTeacher(fixtures.FakeTeacher):
    calls = 0
    def probabilities(self, candidates, **kwargs):
        self.calls += 1
        return super().probabilities(candidates, **kwargs)

teacher = CountingTeacher()
engine = SemanticASRTranscriber(
    fixtures.FakeAdapter(), teacher=teacher,
    evidence_budget=EvidenceBudget(total_cost_ms=0, max_actions=0),
    teacher_policy=DelayedTeacherPolicy(minimum_entropy=0),
)
with tempfile.TemporaryDirectory() as directory:
    source = Path(directory) / 'fixture.wav'
    source.write_bytes(b'fixture-only')
    result = engine.transcribe(source, duration_ms=1000)
    row = result.segments[0]
    print(teacher.calls, len(row.actions), row.diagnostics['evidenceBudgetUsedMs'])
```

Observed: `1 0 0`. Expected new inference count at zero budget: zero.
Issue #24 specifies regression cases, cache semantics and planned versus real cost.
This documentation change does not fix the defect.

### #25 — a probability can claim calibration without a receipt

```python
from semantic_asr.score_semantics import EvidenceScore, ScoreKind
score = EvidenceScore(0.9, ScoreKind.PROBABILITY, 'fixture', calibrated=True)
print(score.calibration_digest, score.require_probability())
```

Observed: `None 0.9`. A separate EvidenceScore in score_types.py has different
semantics. Issue #25 requires a canonical migration and validation against an
applicable calibration profile, not merely a non-empty digest string.
