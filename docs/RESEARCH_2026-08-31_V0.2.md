## 2. Context7 runtime findings translated into contracts

### faster-whisper

The current public API exposes decoder controls such as beam size, temperature fallback, prompt/hotword injection, repetition penalty, no-repeat n-gram size, VAD, CPU thread count and concurrent workers. v0.2 therefore treats every decoding option as evidence provenance rather than a hidden global setting.

Hotwords are a prompt bias, not acoustic proof. A hotword match contributes lexical/context evidence and must not be mislabeled as independent acoustic support.

### CTranslate2

CTranslate2 finalizes beam scores using length normalization. The v0.2 path adapter recovers cumulative path score before duplicate-surface aggregation. `return_scores`, token/path output and, in future experiments, vocabulary logits are retained as decoder evidence.

Static prompt/KV reuse and quantization are runtime optimizations. They are benchmarked separately because cache reuse and changed batch shape may affect exact numerical reproducibility.

### Transformers

A causal LM scorer uses teacher-forced token log probabilities across the supplied candidate. It does not use the largest unrelated next-token probability and does not ask a chat model to print a probability. Quantization is an execution choice recorded in provenance.

### llama.cpp-compatible serving

Dedicated `/v1/rerank` output is treated as an uncalibrated reranker score. Server timing data is recorded for quality/cost evaluation. Prompt-cache reuse is disabled for bitwise reproducibility experiments and enabled only in a separately named runtime condition.

## 3. Implemented direct mechanisms

### Typed score semantics

`src/semantic_asr/score_types.py` separates:

```text
cumulative log likelihood
average log likelihood
log probability
probability
logit
uncalibrated score
preference
loss
cost
```

A value in `[0, 1]` is not automatically a probability. Only a fitted held-out calibrator can construct a calibrated probability.

### Decoder-path mass preservation

`src/semantic_asr/candidate_pool.py` and `adapters_v2.py` retain every decoder path and aggregate paths that decode to the same surface with `logsumexp`. The old best-path-only deduplication remains an ablation.

### Existing-candidate semantic MBR

`src/semantic_asr/mbr.py` minimizes posterior expected character, mora and meaning-critical loss over existing candidates. A consensus string outside the N-best list is a proposal and cannot directly become observed evidence.

### Adaptive K with finite-sample control

`src/semantic_asr/risk_control.py` fits conservative upper risk bounds over candidate-count/stage policies. Fixed K, heuristic adaptive K and risk-controlled K remain separate systems in the experiment table.

### Proper sequence and reranker scoring

`src/semantic_asr/sequence_scorers.py` includes full teacher-forced causal sequence scoring and a dedicated loopback reranker endpoint. Chat-model authored JSON numbers remain preferences only.

### Learned constrained reranking

`src/semantic_asr/reranking.py` provides a dependency-free constrained linear baseline. `training_v2.py` adds a small sparse-expert neural reranker, an MWER/listwise/pairwise/critical/distillation objective and an acoustic-text verifier.

### Learned evidence scheduling

`src/semantic_asr/planner_v2.py` learns expected loss reduction and platform-specific cost from observed actions. The hand-authored v0.1 planner remains a deterministic baseline.

### Evidence-safe Koemo boundary

`src/semantic_asr/koemo_bridge.py` makes live text provisional, final observed text evidence-bound and readability correction a separate derivative. Koemo regex corrections cannot mutate observed evidence.

## 4. Architecture translations from Qwen3.8-Flash-Next

These are explicit translations, not kernel reproductions.

| Source idea | Semantic ASR translation | Falsification |
|---|---|---|
| selected/sparse local computation | invoke second listening or verification only on contradiction islands | compare with always-on second pass at matched risk and report invocation rate/RTF |
| dynamically gated branches | sparse specialist reranker with a hard minimum acoustic branch | ablate router, experts and acoustic floor |
| local n-gram/context augmentation | rights-gated char/mora/subword memory | compare each granularity against ASR-only and learned reranker |
| efficient long-context processing | consensus locking, span cache and hierarchical meeting state | compare full reprocessing with incremental cached execution |
| draft/verify execution | compact reranker proposes; acoustic verifier accepts/rejects | compare verifier with full second-ear ASR on quality/cost frontier |

No Qwen attention table, kernel or weight is copied.

## 5. Specialist-expert hypothesis

A generic language score is often unnecessary. v0.2 tests small experts for:

```text
numbers and units
dates and times
currency and percentages
negation and modality
proper nouns and technical terms
particles and special mora
fillers, restarts and learner-error preservation
```

The router receives uncertainty, semantic criticality and platform state. Experts emit typed evidence, not corrected text.

**Hypothesis:** specialist routing gives lower critical-token loss per millisecond than always invoking one larger LLM.

**Reject when:** the routed system is dominated by a compact single reranker or worsens calibration under domain shift.

## 6. Draft/verify acoustic model hypothesis

A compact verifier receives acoustic embeddings and a candidate mora/phone representation. It combines global text-conditioned acoustic pooling with local frame/token compatibility.

Training examples combine:

- real N-best competitors;
- Qwen/Whisper cross-model disagreements;
- long-vowel, sokuon, moraic-nasal and particle negatives;
- number, date, currency and negation negatives;
- guarded generative proposals;
- human/reference-aligned positives and negatives.

**Hypothesis:** a verifier is cheaper than rerunning a full second ASR model while rejecting fluent but unsupported corrections.

**Reject when:** it does not improve critical loss, calibration or the quality/RTF frontier against forced alignment and second-ear baselines.

## 7. Guarded generative correction

Generative error correction is delayed until existing-candidate ranking remains uncertain. Generated text is marked as a proposal and must pass acoustic verification. The test matrix includes:

```text
existing candidates only
generative proposal without acceptance
generative proposal + forced alignment
generative proposal + compact verifier
generative proposal + second-ear confirmation
```

The direct-generation condition is measured only as an unsafe research baseline and can never populate `ObservedTranscript` in production code.

## 8. Audio-conditioned Japanese LLM track

The `llm-jp-asr` pattern suggests:

```text
Whisper encoder -> temporal projector -> compact Japanese decoder LM
```

This is deliberately Phase 3. First, second-pass reranking measures the achievable gain from textual priors. Only after the upper bound is known do we compare:

1. frozen encoder + projector;
2. frozen decoder + projector;
3. projector + decoder LoRA;
4. joint auxiliary mora/phone losses;
5. quantized CPU/small-GPU inference.

The acceptance metric includes acoustic fabrication and preservation, not CER alone.

## 10. Training and distillation hierarchy

```text
large offline teacher (optional 8B/12B+)
  -> candidate preferences and hard-negative analysis
  -> compact 0.6B quality reranker
  -> 100M-class CPU cross-encoder
  -> constrained linear and n-gram fallback
```

The teacher never defines ground truth. Reference transcripts, acoustic verification and held-out evaluation remain authoritative. Teacher preference is retained as an uncalibrated feature and distilled only when it improves locked test metrics.

## 12. Claim boundary

The branch implements algorithms, contracts, training modules and validation harnesses. It does not claim measured Japanese recognition improvement until real model weights, rights-approved datasets and speaker-disjoint locked evaluation have been executed. Unit tests establish deterministic contracts, not ASR accuracy.
