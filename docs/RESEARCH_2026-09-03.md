## 1. First long-form run

Input: 40 locked-test ReazonSpeech clips concatenated with 0.6 s gaps (271.9 s, 1,036 reference
characters, `data/longform/reazon40.*`, outside the repository). `transcribe-v2` with the
`cpu-quality` effort (beam 12, evidence budget 4 s, Whisper re-listening enabled).

| run | wall | lenient CER | strict CER | provisional windows |
|---|---|---|---|---|
| v0.2 long-form as merged in #13 | 478 s | 0.1551 | 0.1786 | 11 / 11 |
| after the two fixes below | 221 s | 0.1265 | 0.1515 | 7 / 11 |
| facade `cpu-ja-v1` (beam 5, no re-listen), before fixes | 314 s | 0.1316 | 0.1564 | 11 / 11 |
| facade `cpu-ja-v1` after the fixes | 221 s | 0.1306 | 0.1554 | 5 / 11 |

### Defect A — sub-span re-listen decodes became window candidates

A contradiction-island re-listen of 134.9–135.2 s returned 「お届けする」. The row was merged into
the 28 s window pool and won on average log-probability, so the whole window (107–135 s)
collapsed to five characters. Sub-span rows are now *evidence*: they raise `cross_model` for
window candidates that contain their text (`apply_span_evidence`) and are recorded under
`spanEvidence`; only decodes covering the full window may join the observed-eligible pool.

### Defect B — punctuation variants flattened the posterior

Beams that differ only in 、。！ placement were separate candidates, so entropy was ≈0.92 in every
window and all eleven windows were `provisional`. Long-form windows now pool punctuation,
symbol and whitespace variants into one surface class before fusion (`policy="lenient"`); the
strongest path keeps its own surface. Candidate count per window fell from ~12 to 3–6, which is
also why the run is twice as fast.

## 2. Is the gate informative? (600-clip candidates, lenient pooling, default fusion)

`needs_relisten` fires on 97–98 % of clips, so as a flag it carries no information. The fusion top
posterior does:

| split | AUROC top posterior → lenient-exact | accepted at ≥0.64 | exact-ok accepted / rejected |
|---|---|---|---|
| calibration (n=119) | 0.759 | 47 % | 0.61 / 0.27 |
| test (n=116) | 0.800 | 42 % | 0.69 / 0.22 |

A Platt map from logit(top posterior) to P(lenient CER = 0) fitted on the calibration split gives
test ECE 0.180 → 0.029 (Brier 0.210 → 0.201; slope 0.121, intercept −0.669). The slope is small:
the calibrated value is a usable *ranking* signal for reviewers, not a guarantee, and it was fitted
on 1–30 s clips while long-form segments are 28 s windows. The facade exposes it as
`TranscriptSegment.confidence` with that note attached to the profile.

## 3. Facade

`semantic_asr.transcribe(audio, profile="cpu-ja-v1")`, `transcribe_segments()` (Koemo contract)
and `semantic-asr run` route through the same long-form orchestrator with frozen, digestible
profiles. `cpu-ja-v1` processes the 272 s recording in 221 s (RTF ≈0.8 including model load) after the
fixes; lenient pooling reduces the candidate set and therefore the evidence work.

## 4. Claim boundary

- One 272 s concatenated recording; boundaries are artificial (0.6 s gaps) and references keep the
